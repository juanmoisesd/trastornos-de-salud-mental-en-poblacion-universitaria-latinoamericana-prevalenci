# Reproducibility Guide

## Dataset: trastornos de salud mental en poblacion universitaria latinoamericana prevalenci

---

## 1. Requirements

- Web browser or data analysis software (R, Python, Excel)
- No special software required for basic data access

## 2. Data Access

```
# Clone repository
git clone https://github.com/juanmoisesd/trastornos-de-salud-mental-en-poblacion-universitaria-latinoamericana-prevalenci.git
cd trastornos-de-salud-mental-en-poblacion-universitaria-latinoamericana-prevalenci
```

## 3. Data Format

- Data is provided in standard CSV/HTML format
- UTF-8 encoding
- See `data_dictionary.csv` or README for variable descriptions
